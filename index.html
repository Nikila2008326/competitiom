Firestore Security Rules

Paste these rules into your Firebase Console to allow saving

ඔයාගේ Firebase Console එකේ Firestore Database > Rules ටැබ් එකට ගිහින් පහත කේතය paste කර Publish කරන්න: 

rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

💡 මේ rules එක දැම්මාම permissions error නැතුව database එකට දත්ත කෙලින්ම save වේ.
